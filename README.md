# RV-32I
![](img/rv32i_core.png)

## Overview & Objectives
This project centers on the design and implementation of a 32-bit RISC-V (RV32I) core chip. The primary goal behind building it was to gain hands-on experience with RISC-V processor architecture and sharpen my Verilog HDL skills.

Beyond core logic design, the project served as a practical deep dive into modern digital ASIC flows—specifically focusing on clock tree synthesis (CTS) and exploring the automated physical design pipeline using OpenLane 2.0.
